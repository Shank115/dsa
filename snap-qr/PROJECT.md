## How to run (local testing)
```
pip install "qrcode[pil]"
python server.py      # serves site/ on :8000, prints phone URL, owner link, private stats link
python make_qr.py     # qr.png for this PC's LAN address (phone must be on same Wi-Fi)
python make_memes.py  # after adding screenshots to meme/
```
- Phone URL: `http://192.168.0.101:8000` (PC's LAN IP; check `server.py`'s printout if it changes). Use `http://`, not https.
- Owner link `/?owner=KEY` (open once on own phone → scores get the 👑 crown).
- Private stats + messages: `/stats.html?key=KEY`. KEY lives in `data/owner_key.txt` — keep it secret.
- Windows Firewall allows Python (Public profile). Phone must be on the same Wi-Fi ("B Brothers pg…").
- After editing `server.py`, **restart the server**; site files are served fresh (no-store), just reload.

## Features (current)
- **Profile**: rounded-square "app icon" avatar (lime → purple gradient, black "S"), name in the lime → purple gradient,
  **typing roles** in mono ("Software Engineer 💻", "Barça till I die 🔵🔴", "Messi is the GOAT 🐐", "Always planning the next trip ✈️").
- **"Bored? I got you." carousel**: three cards side by side, swipe left/right (each card 86% wide so the next peeks in),
  tabs **🧱 Stack · 🎯 Knife · 😂 Memes** (each tab has `data-card`; a hidden card hides its tab) and dots built to match.
  First visit: one slide-and-back nudge. Order: Stack, Knife, Memes.
- **🧱 Stack Tower**: tap to drop blocks, overhang falls off, speeds up. Perfect drops show **Gen Z compliments** that escalate
  (Nice! → Awesome! → On fire 🔥 → GOAT 🐐 / Messi-level 🐐). **Rainbow colours** (random start hue, shifts per block, colourful sky).
- **🎯 Knife Hit** (his pick for an "addictive" game): tap to throw knives into a spinning target; hitting a stuck knife ends it.
  6–9 knives per stage, pre-stuck knives from stage 2, spin patterns (steady, speed up/slow down, reversing), **boss every 5th
  stage** (👑, 10 knives, erratic). 🍎 on the rim = +2. Target shatters on stage clear; colours change every stage.
  Score = knives stuck (+ apple bonus).
- **Both games share** one game screen, game-over sheet (score, new best + confetti, aura, name form, rank, Play again, Add me,
  Challenge) and the leaderboard modal — `GAMES` in `main.js` holds per-game engine, demo, "Your best" key (`stackBest` /
  `hitBest`), share text. Each game has its **own "Your best"** and **own leaderboard**. Game events carry `game: "stack" | "hit"`.
- **Leaderboards**: name saved once (`playerName`), best score per player per game, owner gets 👑.
  A player only appears after saving a name (that confused him once: "Your best 67" but an empty board).
- **Challenge** (game over): native share sheet on https; on http falls back to **WhatsApp** + **Copy link**.
- **😂 Meme scroll**: card with a fan of 3 changing previews, "**1000s** of memes, fresh shuffle every time." → full-screen feed
  **inside index.html** (not a new page, so music keeps playing). Reels-style vertical snap scroll; **fresh shuffle on every open,
  unseen memes first**; **endless** (new shuffled round appended near the bottom, no back-to-back repeat, no end card).
  Loads only nearby images (2 behind, 5 ahead; releases >15 away). Action row: **♡ Like** (also double-tap), **Share** (sends
  the meme as a JPEG — WebP becomes a sticker on WhatsApp), **😂 React**. A "Add me on Snapchat" card every 15 memes.
  **Never show how many memes there are** (his call): no counter in the feed header (only Back).
- **Emoji reactions** (replaced the per-meme "Add me" button): React → tray of quick picks **😂 💀 🔥 😭 🥀**, then any other
  emoji people used on that meme (most used first), then **➕** → "React with anything" sheet (98 popular emojis + a box to type
  **any** emoji). **No restriction on emojis** (his call). One reaction per phone per meme (`memeReacts`), tap again to remove,
  emoji floats up, everyone sees counts. Server `is_emoji()` accepts exactly one emoji (skin tones, ZWJ combos, flags ok;
  text/junk/multiple rejected), max 60 different emojis per meme.
- **Anonymous messages** (NGL-style) with tap-to-fill prompts; only readable on the private stats page; 5 per 10 min per network.
- **Aura ✨** (top-right pill): server-side awards with limits — daily check-in +50, QR scan +100 (once), Stack +15/block +40/perfect,
  **Knife Hit +12/knife**, challenge +200 (3/day), fumbling the first block / missing the first knife −50. **No aura for memes.**
  Titles: NPC 😐 → Side character 🙂 → Rising star ⭐ → Main character 💅 → Aura farmer 🌾 → Sigma 🗿 → GOAT 🐐.
  No login: aura is tied to an anonymous browser ID (localStorage); the aura screen says to stay on the same phone + browser.
- **Live counter** (top-left pill): "12 vibing here rn 👀" / "just you rn 🫠" (ping every 20 s, 45 s window).
- **Background music 🎵**: soft piano rolling chords + **tanpura drone** + string pad + quiet bass, 72 BPM,
  G–D/F#–Em7–Cmaj7 | G–D/F#–Cmaj7–Dsus4–D. **No lead melody, no drums, no builds, no bright sounds** — smooth, background only.
  Generated in code (no copyright issues). Volume 32% master (quieter than game SFX), fades in, pauses when the tab is hidden.
  - Starts on the **first tap anywhere** (finger-up events). Browsers never allow sound before a tap; scrolling doesn't count.
  - Toggle = equalizer **bars** button left of the aura pill (he chose bars over a ♪ icon); choice saved (`music`).
    Crossed-out bars mean both "off" and "waiting for first tap".
  - Plays even on **silent mode** (his wish; only volume 0 / the toggle stops it): iPhone uses `audioSession.type = "playback"`
    (iOS 16.4+) or a silent looping `<audio>`. Music works on his iPhone (iOS 18, Chrome); silent-switch case not yet confirmed.
  - Reload-safe: audio released on `pagehide`; a player that ignores a tap for >0.5 s is replaced on the next tap.
- **Connect with me**: Snapchat button in exact Snap yellow `#FFFC00`, ghost logo (white with black outline).
- **Effects**: tap sparkles, confetti (new best / message sent / level up), gentle card tilt on desktop.
- **Owner stats page**: visits, QR scans vs direct, unique visitors, Snap taps, games (with which game), top scores (Stack + Knife),
  both leaderboards, memes (scrolls, viewed, likes, reactions, top 12 memes with emoji counts), messages, daily table, recent activity.

## Dev notes
- Testing: Python Playwright driving local **Edge** (`channel="msedge"`) at 390×844 (`has_touch`, `is_mobile`). Node here is 18.
  Run Python with `-X utf8` (emoji output). Put Python scripts that contain emojis in a file (Write tool) — inline heredocs break.
- **Don't pollute or overwrite his real data**: block `/api/track` in tests, or back up `data/` and restore after.
  Careful: restoring after a test also wipes anything **he** did meanwhile (it erased his real Knife Hit 42 once) —
  check the server log for his phone (192.168.0.100) before restoring, or test with tracking blocked.
- Use `--autoplay-policy=document-user-activation-required` to test music like a phone; Edge otherwise allows autoplay.
- Debug lesson: "music not playing" on his iPhone was the 🎵 toggle saved as OFF (`music=0`), not a bug. Ask him to check
  the 🎵 bars first. A white screen on his phone was a stuck tab — close the tab and open a new one.
- `snap-qr` is not a git repo (the `E:\Python\dsa` repo is separate); `.backup/` holds manual backups.
